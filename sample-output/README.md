# Sample Output (Illustrative)

The files in this folder contain fictional values for demonstration and are **not output captured from a running database**. Set up the backend, create warehouse/product/supplier records, then perform stock movements to generate actual output.

- `dashboard-summary.json`: sample response from `GET /api/summary`.
- `inventory.csv`: sample structure for `GET /api/stock.csv`.
- `purchase-orders.json`: sample purchase-order states and quantities.
- `../docs/dashboard-preview.svg`: illustrative React dashboard layout.
